# 算法目录维护说明

目录以飞书公开页面《算法板子与要点》为基础，现按知识关系重组实际层级；原始 Part 编号只作来源索引，不再约束节点父级和显示次序。颜色与明确五档来自用户提供的 Markdown。仅提取目录和必要学习次序，不复制飞书正文代码。

- [整合目录与逐项评估](<../XCPC算法目录_飞书结构与难度整合.md>)：用户主要交付文档。
- [可编辑目录数据](<../../data/algorithm-directory.json>)：应用和 Markdown 的共同数据源。
- [分类标题优化对照](<../XCPC算法目录_分类标题优化对照.md>)：当前简洁名称、179项标题简化记录、历次改名理由与全部原始标题的对应。
- [结构优化说明](<../XCPC算法目录_结构优化说明.md>)：实际模块分组、移动与合并的前后记录；源数据的 sourceIndex 保留全部原始章节的当前路径。
- [原飞书目录快照](<feishu-outline.json>)：126 个原始 Part 标题。展示标题可优化，原标题与章节编号保留在数据中。
- [颜色文档覆盖表](<color-md-coverage.json>)：99 条原清单逐条对应当前节点。
- [难度评估依据](<difficulty-evidence.json>)：全部 577 个节点的适用状态：386 个具体算法与模型的定稿等级、范围、依据和证据强度；191 个目录明确标为不评级。
- [本轮评级定稿说明](<../XCPC算法目录_难度评级定稿说明.md>)：分布统计、等级调整与树形背包模型约定。
- [逐项评估附录](<difficulty-assessment.md>)：按 Part 分组的人类可读难度依据，参考来源统一编号。
- [来源摘录](<sources.json>)：参考页面的短摘录与核验记录。
- [本次优化说明](<../XCPC算法目录_本次优化说明.md>)：归类、去重、难度和阅读体验的具体前后变化。
- [旧节点映射](<legacy-node-map.json>)：全部 367 个历史节点标识仍可定位，新建笔记使用当前标识。

五档为 D1 入门、D2 初级、D3 中级、D4 高级、D5 挑战。模板、常用、低频分别存于 attributes，不占用难度字段。用户明确分档保留；其余是本项目根据先修知识、建模与证明、实现负担的学习评估。来源没有授予统一五档，USACO 分区不等同于 XCPC 奖牌。分类与先修参考的置信度低于专题与先修参考。具体算法与明确模型使用 rating.status=confirmed；全部目录、分类与入口使用 color=parent、rating.status=not-applicable、rating.type=directory，不显示难度或跨度。原473个节点的标识、名称、父级、相对顺序和已有笔记关联保留。104个原目录含有具体算法内容，因此分别新增 algorithm-content-<原标识> 子节点，使用 contentOf 指向原目录，承接原等级、范围与证据；85个纯分类及2个入口不凭空新增算法。原282个算法叶子节点完整保留。定稿状态不改变证据强度，也不把未知来源内容当作已确定的算法。

源数据的 editorial.directorySeparation 记录原473个节点的身份、父级及原子节点顺序快照，并保存新增算法对应关系。算法原始对象的 SHA-256 用于验证原叶子内容未被修改。历史标识依然指向原目录，已有笔记不迁移；颜色清单与评级证据在拆分时改为指向具体算法子节点，明确分档不再落在目录上。titleSimplification.reviewed=473 保留原标题审校轮次，新增子节点的完整名来自该轮179项简化前名称。

修改目录数据后执行 `pnpm algorithms:build` 同时重新生成应用目录与 Markdown，执行 `pnpm algorithms:check` 检查生成文件一致性；`node --test tests/algorithm-directory.test.cjs` 检查原目录、颜色清单和历史笔记兼容。浏览器验收为 `node tests/algorithm-notes-ui-smoke.cjs`。

当前改动仅在本地工作分支整理，未发布新版本。
