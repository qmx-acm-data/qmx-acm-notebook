# XCPC 算法目录优化说明

本次在已有整合文档上做内容审校与阅读优化，保留飞书主线与原始颜色文档，未发布客户端版本。

## 当前目录与算法分离规则

以下归类、去重及初次补评表保留历史操作记录。当前结果以[完整目录](<XCPC算法目录_飞书结构与难度整合.md>)和[评级定稿说明](<XCPC算法目录_难度评级定稿说明.md>)为准：保留原473个节点全部标识、名称、位置及笔记关联；191个目录与入口不评级。104个原目录中的具体算法内容另建同名子节点承接原等级和证据，形成577个总节点、386个已评级算法与模型（181原档、205补评）。原282个算法叶子对象完整保留；原目录不以算法节点替换。

## 阅读体验

- 主文档加入可点击的 Part 导航、四阶段学习安排和每阶段完成标准。
- 加入六条学习依赖参考，说明箭头是建议串联顺序，不要求并列专题彼此互为先修。
- 将原来超过200行的逐项难度大表移入独立附录，按 Part 分组并给参考来源编号。
- 在主目录直接区分〔原〕、〔评〕与〔评·待复核〕；低置信度不再与专题依据充分的补评混写。
- 为 Dijkstra、SG、逆元、FFT/NTT、ODT 等补充适用条件。当前目录不评级；具体算法在对应子节点中独立标注难度。

## 内容归类与去重

| 条目 | 具体改动 |
| --- | --- |
| 计数 DP | 合并重复的“基础”和“进阶”；简单计数状态单列，计数 DP 总项保留 D3 原档。 |
| 欧拉函数、Lucas、轮廓线 | 合并同名自嵌或重复的普通阶段节点；保留 exLucas 和插头 DP。 |
| 概率、期望、计数、图上、自动机等 DP | 从线性 DP 移到补充模型分支；基环树 DP 移到树形 DP。 |
| Kosaraju | 从点/边双连通分支移到“强连通分量（有向图）”，与 Tarjan SCC 并列。 |
| 斐波那契堆 | 从二叉堆下移到可并堆。 |
| Floyd–Warshall | 算法主体移到最短路；传递闭包保留为可达性应用并附交叉引用。 |
| 边分治 | 与树上分治相关算法并列，避免误认为点分治子类。 |
| BEST 定理 | 从矩阵子项移到组合数学，并关联矩阵树定理。 |
| 类欧几里得、佩尔方程 | 移到整除相关，避免误作数值积分或高次同余。 |
| 单调栈优化 | 移到数据结构优化 DP，区别于决策单调性。 |
| 多重背包复杂度 | 改成“朴素枚举件数 / 二进制分组 / 单调队列优化”，说明 n、W、C 和对应复杂度。 |
| 树形背包 O(n³)/O(n²) | 缺少具体状态与模型，仅保留“待补模型”记录，不再当作独立算法或确定难度。 |

## 难度与来源修正

| 条目 | 优化前 | 优化后与原因 |
| --- | --- | --- |
| Kosaraju | D4 综合评估 | D3 综合评估；基础范围为两次 DFS、完成序与反图求 SCC。 |
| 条件概率 | D4、低频 | D2 综合评估；范围明确为定义、乘法/全概率公式与独立性。 |
| 最短路径树 | D4 | D3 综合评估；仅指记录前驱构树，不包含树计数等更难应用。 |
| 错排问题 | D1 | D2 综合评估；包含递推和简单计数证明。 |
| 扫描线 | D2 | D3 综合评估；范围为事件排序与活动集合，复杂几何应用可更难。 |
| 懒标记区间修改/查询 | D2〔原〕且重复 | 与带标记线段树合并为 D3〔评〕；原文粉色只表示常用。 |
| FWT/FMT | 捆绑 D5〔原〕 | FWT 保留 D5〔原〕；FMT/SOS DP 单列 D3〔评〕。 |
| 递归、回溯、递推 | 原档范围混在一起 | 递归 D1〔原〕；回溯 D2〔评〕；递推 D1〔评〕；迭代仍 D1〔原〕。 |
| LCM | 仅历史 GCD/LCM 标识，正文无单项 | 补最小公倍数 D2〔原〕，明确先除后乘和溢出。 |

原文明确给出的 SAM、PAM、FWT、Prüfer、Burnside/Pólya、Lyndon/Duval 等分档继续保留。本次改变的是重复节点、综合评估和过度扩大的“原”标识，不把训练建议宣称为各来源统一认可的官方等级。
