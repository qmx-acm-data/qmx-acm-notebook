# 算法笔记

算法笔记使用 `algorithms/notes/` 下的 Markdown 文件保存，frontmatter 约定如下：

```yaml
schema: 3
note_scope: public # public 或 personal
node_id: dp-knapsack
featured: false
author_id: 123
author: github-login
title: 0/1 背包状态设计
tags:
  - 动态规划
  - 背包
client_id: uuid
updated_at: 2026-11-08T00:00:00.000Z
```

公共笔记位于 `algorithms/notes/public/`，个人笔记位于 `algorithms/notes/personal/<GitHub-ID>/`；公开范围只展示公共笔记，我的笔记只展示当前作者自己的笔记。普通用户只能创建或编辑自己的个人笔记，管理员可以维护公共笔记、Markdown 简介及多篇精选；设置新的精选不会取消其他笔记的精选。精选设置保存到 `algorithms/node-content/<节点ID的SHA256>.json`，包含 Markdown `introduction` 和多个精确笔记路径 `featuredNotePaths`，不复制笔记正文。保存时后端重新核验管理员、同一叶子归属、笔记范围与版本 SHA。

客户端提供知识树与四阶段学习路线。只有真实算法叶子保存笔记；物理分支和明确创建的空目录只组织子节点，不提供笔记上传或目录笔记列表。已有算法新增子节点时，原内容由 `algorithm-content-<原ID>` 叶子承载，原笔记身份和简介通过别名解析保留，不移动已有 Markdown 文件。提交答案题、算法竞赛经验与游记这类实际内容端点显示为未分级知识点，不再误标目录。

具体叶子统一显示“简介 → 精选笔记 → 全部笔记”三部分，全部笔记排除当前精选，公共与个人范围都使用同一阅读结构。简介按 Markdown 安全渲染，管理员可编辑并实时预览；精选支持多选。无法在当前范围读取或已失效的旧精选引用可取消勾选移除，不会因普通编辑静默清空。

学习参考难度分为入门、初级、中级、高级、挑战五档，颜色仅用于学习顺序参考，不代表客观比赛难度；未指定难度的知识节点显示“未分级”，目录本身不参与分级。模板、常用、低频作为独立属性筛选，不混入五档难度。

搜索可匹配算法名称、完整目录路径、笔记标题、标签或作者，空格分隔的关键词需要同时匹配，可结合难度与属性。“仅看已有笔记”立即按当前公开／个人范围过滤，保留有笔记的叶子与必要祖先路径；关键词、难度和属性仍由搜索按钮或回车提交。

无筛选条件时，重新进入、无条件刷新搜索或清除筛选恢复根目录选中与嵌套收起；存在有效搜索、难度、属性或已有笔记条件时，继续自动展开命中路径，不丢掉条件展开逻辑。通过路线或笔记明确定位某个知识点时，仍展开该目标的祖先。阅读返回保留当前列表位置，切换公开／个人范围退出当前阅读。

学习路线的范围节点属于目录，不直接存放或聚合展示笔记。点击后显示一个 Markdown 简介与实际叶子入口，进入叶子才显示相同的三部分阅读器。原核心目标、注意事项、练习和题单等说明统一收进可编辑的 Markdown 简介，不再分别堆叠信息模块；旧题单与进度数据保留。路线目录简介按 `roadmap:<节点ID>` 独立保存，不能因共享旧课程条目而互相覆盖，也不能关联精选笔记。

节点与笔记仍可使用“打开详情”进入聚焦阅读，保留顶部、侧栏与路径返回；Markdown 预览和正文沿用现有安全渲染器。

正文支持 Markdown、行间公式和内联 `$...$`、`\(...\)` 公式；代码块中的美元符号不会被当作公式解析。笔记目录、权限范围与上述 frontmatter 格式保持不变。
