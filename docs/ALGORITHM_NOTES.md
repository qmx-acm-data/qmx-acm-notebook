算法笔记使用 `algorithms/notes/` 下的 Markdown 文件保存，frontmatter 约定如下：

```yaml
schema: 3
note_scope: public # public 或 personal

featured: false
author_id: 123

title: 0/1 背包状态设计
tags:
  - 动态规划
  - 背包
client_id: uuid
updated_at: 2026-11-08T00:00:00.000Z
```

公共笔记位于 `algorithms/notes/public/`，所有用户可阅读；个人笔记位于 `algorithms/notes/personal/<GitHub-ID>/`，仅作者可阅读。普通用户只能创建或编辑自己的个人笔记，管理员可以创建、编辑公共笔记和设置精选笔记。设置新的精选笔记时，客户端会先取消其他公共笔记的精选标记，保持同一时刻只有一个精选笔记。

客户端的“算法笔记”页提供包含 578 个节点的 XCPC 知识目录，包括可关联经验分享和比赛游记笔记的“算法竞赛经验与游记”目录。闯关学习第0章首关为“总览算法竞赛”，可与该目录双向跳转；原第1—14章和已有进度保留。左侧按父子层级展开、折叠和选择节点，右侧显示路径、子目录与节点笔记；可用方向键移动和展开/折叠，按 Enter 查看。目录行与知识节点分别标识，浅色、深色和卡片主题均提供对应配色。

学习参考难度分为入门、初级、中级、高级、挑战五档，颜色仅用于学习顺序参考，不代表客观比赛难度；未指定难度的知识节点显示“未分级”，目录本身不参与分级。模板、常用、低频作为独立属性筛选，不混入五档难度。

搜索可匹配算法名称、完整目录路径、笔记标题、标签或作者，空格分隔的关键词需要同时匹配；可结合参考难度与属性筛选。结果保留命中节点的祖先层级，并跨节点展示匹配笔记。点击笔记进入阅读视图，再点击“返回目录与笔记”可恢复列表位置；当前会话内返回算法页或重新渲染时保留搜索、筛选、节点选择、展开状态与滚动位置，不承诺重启后恢复这些浏览状态。公开笔记与我的笔记仍按各自范围展示，切换范围会退出当前阅读。

知识树将精选笔记单独前置，节点说明、“添加算法”和“在学习路径中查看”等操作收在内容下方。节点预览、笔记阅读与闯关关卡预览均可点击“打开详情”在“知识树 / 闯关学习”切换栏下方展开阅读，保留顶部与侧栏。详情顶部显示可点击的节点或章节路径，点击“返回上一级”或按 Esc 逐级返回；保留当前选择与阅读位置。关卡详情优先展示相关笔记、学习内容与进度操作，关联知识、先修和分享入口置后。从关卡打开笔记会直接显示该篇正文，关闭后继续原关卡。

正文支持 Markdown、行间公式和内联 `$...$`、`\(...\)` 公式；代码块中的美元符号不会被当作公式解析。笔记目录、权限范围与上述 frontmatter 格式保持不变。
