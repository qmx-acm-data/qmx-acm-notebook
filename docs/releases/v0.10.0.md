# 拾题 v0.10.0 · 多平台做题与比赛总览

- 设置新增 Codeforces、AtCoder、洛谷、牛客、力扣公开主页绑定。粘贴主页链接即可，绑定后仅显示用户名，可更换或解绑；不需要平台密码或 Cookie。
- 主页新增统一统计面板，汇总总解题、总提交、最近比赛和每日做题热度图。平台选择只切换这些统计，两张 Rating 图和汇总比赛历史保持显示。
- 展示 CF 与 AtCoder 的完整公开 Rating 变化折线图；鼠标悬停或键盘聚焦时弹出分行信息框，显示比赛名、Rating 变化和可获取的赛时通过题数/总题数。每日格子悬浮框显示日期与总通过数。
- 补充 CF、AtCoder、牛客公开提交与首次 AC 时间线，洛谷使用官方最近 180 天每日通过数据，提交数按主页“提交”栏显示值统计。来源与缺失区间在面板说明中标注；不将未知数据视为零。
- 独立保存绑定与成功数据快照，重启恢复，刷新失败保留旧数据；升级备份包含平台数据。发布包不包含默认个人账号或验收数据。
- 发布前修正 AtCoder Problems 每页 500 条的分页边界，复核同秒记录并拒绝将不完整或与公开通过数矛盾的历史作为完整统计。

本地验收覆盖设置绑定、平台切换、热图、图表、悬浮框、三种主题、窄窗口与重启恢复。CF/AtCoder/牛客的每日题数按每题首次 AC 统计；洛谷使用非实时官方每日通过数，口径与范围有差异。跨平台相同题目不去重。力扣仅公开最近 AC 列表时不推算全年热图；比赛题数不可获取时省略。最终构建与包验收结果见本次发布 Actions。

Electron runtime 保持 40.10.6。Windows 安装程序未进行 Authenticode 签名，macOS 包未签名公证。正式 Release 发布、产物验收并合并签名更新通道后，现有客户端可检查更新；个人绑定不会被发布账号覆盖。
