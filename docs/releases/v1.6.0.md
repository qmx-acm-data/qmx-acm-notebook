# 拾题 v1.6.0 · CLIST 共享缓存与分页同步

本版整合每日一题、离线题库和 CLIST 评分缓存改进，并保留 v1.5.0 的叶子笔记阅读、Markdown 简介及主线新增 Tricks、统一个人收藏功能。

## 主要更新

- 内置 2026-11-22 实际查询的 37,200 条 CLIST 正分；首次启动自动与个人缓存合并，无需 Key。保留较新个人评分、独有缓存、人工和 AI 补充；相同基线不重复写入。
- CLIST 批量刷新改为 API 分页，每请求最多 1,000 条，遵守限流，支持页后保存、暂停和重启续传。单题强制刷新继续保留。
- 支持导出、导入合并评分缓存及公开 HTTPS 共享来源同步；导出不包含 Key、用户名、题解或个人备注。
- 评分缓存数量与本地题库匹配数分别展示。当前 60,918 题验收库可匹配 26,789 道，不能把 37,200 条记录等同于全部题库覆盖。
- AtCoder 完整且大小写一致的同 task ID 在无冲突时可跨比赛路径复用缓存；精确链接优先。
- 洛谷难度名称统一，新增最低／最高等级区间；同档为精确筛选，兼容旧名称。
- 标签选择顶部显示已选标签，支持逐项移除和清空；取消不提交改动。结果中的算法标签默认隐藏。
- 题库同步支持进度、检查点和暂停续传；原生、社区、CLIST 与已审核人工／AI 信息保持来源与优先级。
- CLIST 明确未收录且依赖参考难度时显示偏差提示；CF、洛谷不显示该提醒。零分按无数据处理。
- 优化大缓存的读取与抽题速度；损坏的初始或本地评分缓存不再阻断窗口启动，保留原文件并显示读取错误。

## 数据边界

牛客 CLIST 基线主要是比赛链接，本地 ACM 题库使用全局题号，尚未猜测建立同题映射；LibreOJ 此次 `loj.ac` 正分查询返回 0。CF 原生 Rating、洛谷原生等级及其他原生／社区数据独立保留，跨平台参考分不代表官方等价。

基线仅包含正分、官方题目链接、资源站点和查询时间，SHA-256：`2fafaf15946ca25360242eed932d12bd2b522cb0adf34518f38c03507abe2dad`。
