# 拾题 v1.1.1 · 差分下载与便携更新修复

首次正式提供差分下载能力，整合未发布的 1.1.0 功能与发布工具修复。1.1.0 构建在正式发布前停止，未激活其更新通道。

- 新增独立 Ed25519 签名差分清单，本机旧应用包版本、大小和 SHA-256 匹配时优先下载补丁，复用旧文件重建新版，完整校验后原位置替换。
- 内容分块与 Brotli 压缩减少小更新下载量，只提供比完整应用包小至少 10% 的补丁；界面显示补丁与完整包大小。
- 缺少适用补丁、旧包变化、补丁下载或重建失败时，自动回退已签名完整应用包。完整包清单保持旧客户端兼容。
- 修复发布安装差分附件时的命令行模块循环加载，增加独立进程真实安装回归。
- 移除“我的题解”“学习统计”“讨论交流”入口及页面，保留已有题解、草稿、收藏与任务。本地保存后直接进入详情，可编辑和收藏。
- 便携版文件更新不再要求卸载程序；更新助手启动失败后可在同一进程重新尝试。
- 清理失败下载和已完成升级事务中的应用副本，完整且通过验证的个人数据备份保留最近两份。

**迁移说明：1.0.0 及更早版本没有补丁重建代码，首次升级到本版仍下载完整应用包一次；安装本版后，后续兼容更新才会优先使用差分。旧便携版需退出客户端后用完整新版便携目录覆盖一次，保留个人数据，不需先安装安装版。Electron 运行时变更仍需完整安装包。**

差分大小取决于实际变化，不保证每次小于上一次；目标是相对同一新版完整包降低下载量。验证覆盖真实签名应用包生成与精确重建、只下载补丁的流量计数、签名/基础文件/补丁损坏、重建错误与完整包回退、链接路径保护和重复升级恢复。正式成品验收结果见发布 Actions。
