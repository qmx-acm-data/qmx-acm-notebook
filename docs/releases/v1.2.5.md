# 拾题 v1.2.5 · 连续差分更新与多仓库管理

- 支持跳版本连续差分更新。没有适配本机的直接补丁时，在固定 main 提交的最近 8 次差分清单变更中查找可用链，最多串联 8 段；每段独立验证完整清单和差分清单签名、运行时、版本、大小及 SHA-256，在临时内存中重建中间版，最终只安装最新版并重启一次。
- 累计补丁下载量须小于完整包的 90%，历史链断开、基础包不匹配或任一段下载/重建/校验失败时回退完整包。更新界面显示累计下载进度、补丁段数和回退原因。实际可跨版本数取决于有界历史内的记录及补丁完整性，并非保证跨满 8 个版本。
- 使用官方历史发布包验证 1.2.2→1.2.3→1.2.4：两段补丁共 272,526 字节，最终文件与已签名目标完全一致。已安装的旧客户端需先升级到包含本实现的 1.2.5，之后才能自动连续差分；旧客户端升级到 1.2.5 时仍按原有直接差分或完整包逻辑执行。
- 增加多题解仓库管理，设置中添加、删除和选择仓库，顶栏切换后自动同步。默认使用官方 GitHub 题库，保留原有配置；校内 Gitea 作为可选预设。
- 缓存、权限与收藏按 Git 服务地址和仓库路径隔离，修复同路径跨服务缓存混用、切换时同步被忙碌状态拦截、保存失败未恢复选择和旧设置迁移问题。
- 自建 Gitea 目前仅匿名读取公开仓库。GitHub OAuth 与登录凭据始终限定 GitHub，自建服务不接收 GitHub Token；不支持 GitLab API、自建私有仓库认证或自建服务写入。
- 增加 `pnpm serve:web` 浏览器预览，默认仅监听本机，提供受限静态资源与可配置同步来源；拒绝仓库源文件读取、路径穿越、非授权来源及上游重定向。

升级保留题解、收藏、计划、设置与学习进度。Electron runtime 保持 40.10.6。历史元数据或补丁网络不可用时可回退完整应用包；macOS 继续使用完整安装包手动更新。
