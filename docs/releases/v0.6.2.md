# 拾题 v0.6.2 · 题解难度选择改进

本版本统一新增和修改题解时的难度选择体验，使其与搜索栏使用同一套平台原生难度颜色和选项规则。

- Codeforces 题解使用带原生颜色分级的 Rating 控件和常用区间预设，并保留可选的其他原生难度信息。
- 洛谷使用原生难度选项和对应颜色；LeetCode 使用 Easy、Medium、Hard 原生选项；其他平台保留原生难度输入及常用候选值。
- 编辑已有题解时自动回填 Rating、原生难度和历史上未识别的难度值，不再因控件切换而隐藏或丢失已有信息。
- 粘贴 Codeforces、洛谷、AtCoder 或牛客题目链接后，平台和难度控件同步更新；保存或上传期间锁定难度控件，避免提交数据发生变化。

验证：完整 Node 测试、题解编辑 UI smoke、搜索难度 UI smoke 和搜索逻辑测试均通过；发布构建将由 GitHub Actions 在受保护的 `main` 和 `v0.6.2` 标签上执行。

发布后请在 Actions 中运行 **Prepare published update channel** 并合并生成的更新通道 PR，现有客户端才会在“检查更新”中发现本版本。Electron runtime 未因本版本功能变化而更换，Windows 用户也可直接使用完整安装程序升级。
