# 拾题 v1.0.0 · 紧凑主页与算法知识目录

v1.0.0 整理当前已实现功能，提供紧凑主页、本机学习计划和分层算法笔记目录；保留公开题库、GitHub 题解操作、比赛提醒与多平台统计。

## 功能变化

- 主页统一采用紧凑布局，集中展示比赛提醒、待做题目、学习任务与做题比赛总览，移除六项快捷入口。公共题库、算法笔记、个人收藏、我的题解、讨论与学习统计通过侧边栏访问，侧边栏继续支持悬浮展开与固定。
- 待做题目支持粘贴 Codeforces、AtCoder、洛谷、牛客、力扣、Hydro、AcWing 官方题目链接，名称可选，未填写时按链接生成；支持打开原题、编辑、完成与确认删除。
- 学习任务支持可选截止时间，使用日历与时刻弹窗，按本机时区显示；未完成任务按截止时间排序并标记逾期。点击任务标题打开只读详情，补充任务说明及修改内容通过“编辑”完成。
- 题单与任务保存在 `planner.json`，重启恢复，并纳入应用内升级前备份。数据属于当前设备和系统用户，切换 GitHub 账号或资料库仍使用同一份计划，不上传或同步到 GitHub；设置的本地数据导出不包含该文件，需另行备份。
- 算法笔记采用包含 367 个节点的 XCPC 分层目录，通过展开、折叠、路径导航、子目录卡片与键盘操作浏览。父子层级、目录与知识节点有明确标识，支持浅色、深色和卡片主题。
- 入门、初级、中级、高级、挑战五档仅作学习顺序参考；未分级节点与目录分别标识，模板、常用、低频作为独立属性筛选，不混入难度档位。
- 算法目录支持按算法、路径、笔记标题、标签与作者搜索，并结合难度与属性筛选；保留匹配节点的祖先路径和跨节点笔记结果。阅读后返回列表恢复位置，当前会话内保留搜索、筛选、展开与节点选择状态。
- 算法笔记仍区分公开笔记与当前账号个人笔记；Markdown 格式、节点 ID 与范围权限约定保持兼容，详见[算法笔记说明](../ALGORITHM_NOTES.md)。

## 本地检查与验证范围

本次本地验证已通过以下检查；这些结果说明对应测试场景，不代表所有账号、网络环境和系统均已验收：

- Node 单元测试全量回归通过。
- Edge 算法笔记界面检查通过，覆盖完整 367 节点与稳定节点 ID、目录层级、搜索筛选及阅读状态；浅色、深色、卡片三种主题共 2115 项文字对比度检查达到 4.5:1。
- 原生 Electron 待做题单、学习任务与算法笔记冒烟检查通过；截止时间弹窗的 Edge 检查及夏令时边界测试通过。
- 五份当前文档的本地链接检查通过；题目链接范围、本机计划存储、升级备份与算法目录行为已按源码核对。

真实 GitHub OAuth、组织授权和在线文件增删改需使用实际账号与资料库另行验收；模拟接口、维护工具登录和浏览器演示不能代替这些验证。正式构建与安装包验收结果以本次发布记录为准。

## 已知限制与分发说明

- 个人题解、收藏、复习状态及学习计划不提供跨设备私人数据同步；界面尚未提供备份导入。计划恢复应先退出客户端并保留原文件，详见[使用指南](../USAGE.md#数据安全与备份)。
- 多平台统计依赖公开数据与第三方来源，可能延迟、缺失或受限；跨平台相同题目不去重，不将截断提交历史或未知字段视为完整统计。
- Windows 安装程序未进行 Authenticode 签名；macOS 包未签名和公证，系统可能拒绝打开。既有记录仅证明 macOS 构建及适用测试，不代表已完成真实桌面交互验收；macOS 仍通过完整应用手动升级。
- 正式 Release 成品验收并发布后，还需合并对应签名更新通道，现有客户端才会收到应用内更新；Electron 运行时不匹配时仍需完整安装包。
