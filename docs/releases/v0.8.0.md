# 拾题 v0.8.0 · 主页导航与代码阅读

- 启动默认进入主页，提供我的题解、个人收藏、讨论交流和学习统计快捷入口。
- 左侧导航依次为主页、tricks、公共题库、算法笔记、个人收藏。默认显示图标，悬浮展开；移出立即开始收回，支持三角按钮固定与取消固定。图标保持原位，文字区域以约 0.3 秒滑动，选中背景连为一体。固定偏好在重启后保留。
- tricks 和算法笔记本次为占位分区，内容将在后续完善。
- 代码阅读支持多语言语法高亮、复制与离线格式化；新增 Rust / rs 的 rustfmt 支持，保留 C 系列 clang-format 和 Python Ruff。格式化只改变本次显示，原题解不会自动改写；失败保留原文。
- 设置支持代码字号与行号预览；保存后持久化，关闭或取消会撤销未保存预览。
- 包含此前已合并的 GitHub 登录与额度恢复改进：授权状态与凭据恢复提示、可复制授权地址、系统浏览器打开失败后的手动授权入口，以及登录后重试受限同步。
- 保留平台原生难度和独立补充洛谷难度；调整打包依赖收集，确保离线 Rust 格式化依赖随客户端发布。

用户已完成本地桌面 UI 验收并明确授权发布。自动验证包括 167 项 Node 测试、导航/题解/搜索/账户/阅读设置/代码界面回归，以及打包桌面滑动逐帧和真实 Rust 格式化验证。实际 GitHub OAuth 在线投稿仍未完成独立验收，模拟接口测试不代替真实授权与远端写入。

Electron runtime 保持 40.10.6。Windows 安装程序未进行 Authenticode 签名，macOS 包未签名公证。正式 Release 发布后合并更新通道 PR，现有客户端才会收到应用内更新。
