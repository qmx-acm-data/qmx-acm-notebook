# 拾题 v1.3.1 · 紧凑题目列表与标签选择改进

本版将公共题库与“本地题解”整理为紧凑七列列表，补全本人题解归集与作者头像，并修复编辑表单残留和标签选择弹窗的交互、绘制问题。

## 题目列表与阅读

- 公共题库与“本地题解”按平台、题号、算法标签、题目、难度、作者、更新七列展示，最小行高 42px；窄窗口保留横向滚动，方便对齐查看题目信息。
- 点击题目直接进入阅读，返回时恢复列表的纵向与横向滚动位置，并将键盘焦点放回对应题目。
- “本地题解”包含当前可见的本地记录，以及当前 GitHub 账号在当前仓库上传的正式题解。正式题解按稳定的用户 ID 判断归属，并限制为当前 GitHub 资料来源；其他账号、仓库或自建服务中的同号用户不会被归为本人。
- 列表、收藏卡片和阅读详情统一展示作者名称与头像。GitHub 头像只使用官方 `avatars.githubusercontent.com` 域名；当前账号可使用已缓存头像，图片失败时回退作者首字。自建资料来源不据用户名或用户 ID 请求 GitHub 头像，未绑定旧本地记录也不会随登录账号改变归属。

## 编辑与标签选择

- 打开新记录、切换编辑来源以及保存后，显式重置隐藏的标签与难度字段，避免上一条记录的值残留；重新打开已有记录或草稿时仍恢复其自身内容，保留按来源和账号保存的草稿。
- 同一次标签选择期间复用标签 DOM，搜索通过显示和隐藏现有选项更新结果，勾选同步相同标签，减少反复创建节点导致的滚动与交互开销。
- 标签弹窗使用局部布局与绘制隔离；打开标签弹窗时取消其背景模糊，覆盖上传编辑窗口的标签选择场景。
- 标签分类标题随内容正常滚动，修复多个吸顶标题叠在选项上、遮挡文字或拦截点击的问题；调整选项悬停与焦点样式，保留浅色、深色及窄屏交互。

## 管理员课程编排与公共布局同步

本版包含[管理员课程编排和公共布局同步（PR #52）](https://github.com/qmx-acm-data/qmx-acm-notebook/pull/52)：管理员可编排公共课程的章节与关卡、调整顺序并预览，使用稳定标识保存到当前资料库，按 SHA 检查冲突；成员同步后使用同一公共布局，删除关卡仍保留本机历史进度。该改动未包含在 v1.3.0 中。真实 Electron 已验证布局经 preload 与缓存恢复、非管理员隐藏入口、删除后的历史进度保留及重启恢复；远端写入仍使用隔离模拟夹具。

## 已核实的本地验证

以下结果来自整合 PR #52 后的 v1.3.1 候选。

- 547 项本地检查中 546 通过、1 项因本机符号链接权限跳过；严格类型、生成一致性、语法、算法数据和适用单元检查通过。
- 22 组界面回归通过，覆盖紧凑题目列表、阅读返回位置、本人题解与资料来源隔离、作者头像、表单标签及难度重置、草稿保留和标签弹窗交互与绘制。
- 在本次 Electron 软件渲染环境中，标签弹窗筛选场景的帧耗时样本由约 50–67ms、上传编辑场景由约 83–117ms，改善至约 16.7–16.8ms。该结果仅代表本次环境与采样场景，不是跨设备、驱动或渲染模式的性能保证；界面回归也不以这些帧耗时作为通用阈值。
