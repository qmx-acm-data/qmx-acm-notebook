# 拾题 v1.4.1 · 每日一题与离线题库索引

本版在主页新增“每日一题”，把跨平台随机抽题与本地题库索引结合：抓取一次题目元数据后落盘，日常抽题只查本地，不再每次联网。

## 每日一题

- 主页在“待做题目/学习任务”下方新增独立板块，与比赛提醒、平台总览并列，沿用现有配色与字号。
- 可按题目来源、Codeforces Rating 区间、洛谷难度和算法标签筛选，再点击“试试手气”抽取。
- 抽取结果单独展示：左上角“抽取结果”、题名、题号、来源、难度与完整题目链接；左下可复制链接，右下可“换一道”。
- “换一道”会排除当前题目；没有其他符合条件的结果时保留原题并提示调整筛选。
- 难度加减按钮只调整下一次抽题的洛谷难度，不立即抽题；CF Rating 区间仍可手动输入。
- 算法标签复用题解中的可搜索多选弹窗，未映射标签不参与统一筛选。
- 抽题期间结果区显示等待状态并禁用按钮，结束后恢复；失败时保留上一次题目。
- 启动后自动抽一道，每次启动只抽一次；切换页面返回时显示同一结果，不重复抽取。

## 题目来源

- 支持 Codeforces、AtCoder、洛谷、牛客、力扣与 LibreOJ 六个平台。
- 配置 CLIST 账号后，可把 CLIST 收录的洛谷、牛客题目作为补充来源；账号与 API key 经系统安全存储加密，界面不回显，接口不返回明文。
- 全部来源时先按平台等概率选择，再在该平台内抽取，避免大题库独占结果；也可指定单一平台。
- 各平台公开列表的分页上限、失败与部分成功都会以提示呈现，不伪造题目。

## 本地题库索引

- 抓取题目元数据（题号、标题、链接、平台、原生难度、估算难度、标签）保存为按平台分片的本地索引，抽题改为本地查询。
- 实测约 61,000 道题、磁盘约 22 MB；全部索引加载约 250 ms，单次抽题约 75 ms（原先联网抽取需 20–40 秒）。
- 支持按平台懒加载：指定平台时只读取对应分片。
- 支持增量更新：先探测各平台题量，数量未变则跳过，变大时只抓新增页，单平台失败保留旧数据。
- 板块右上角“刷新题库”手动触发增量更新，显示进度、新增数量与失败平台。
- 索引为空或不可用时回退到实时抓取，不影响首次使用。

## 难度与标签

- 算法标签统一到客户端内置的洛谷标签词典，未映射的标签单独保留，不参与统一筛选。
- 跨平台难度折算保持启发式：Codeforces 使用原生 Rating；洛谷按原生等级折算；AtCoder 使用社区难度加 800 取整；牛客按 1–5 档映射；力扣接入社区竞赛 rating 数据，覆盖率约 77%。
- 所有折算均标注为非官方等价，未知难度不生成估值。
