# 拾题 v0.6.3 · 单难度选择

修正新增和编辑题解时的平台难度选择方式，使每道题只设置一个难度值，并与搜索栏保持一致的颜色和粗体呈现。

- Codeforces 使用单个 Rating 数值控件，上下调整步长为 100；移除区间预设和第二个原生难度文本输入。
- 洛谷使用单个官方难度选项，不要求自由输入。
- 编辑界面沿用搜索栏的难度颜色和粗体样式。

Electron runtime 保持 40.10.6。发布构建将由 GitHub Actions 对 Windows、Linux 与 macOS 运行检查、测试和打包。Release 发布后，需再合并更新通道 PR，现有客户端才会收到应用内更新。
