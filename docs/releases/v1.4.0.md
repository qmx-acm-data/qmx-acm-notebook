# 拾题 v1.4.0 · 学习路线与四阶段知识关系图

本版将原“闯关学习”替换为“学习路线”。通过初窥、入门、基础、进阶四阶段，展示算法知识的层次与联系，保留按问题自由跳学和回补的方式。

## 学习路线

- 默认显示包含33个知识范围节点、38条连接的关系图；顶部阶段按钮用绿、蓝、金、红标识四个内容层次。
- 自动适应窗口，支持100%、手动放大缩小、搜索、列表切换及关联高亮；小屏也默认关系图，放大后在图内横向浏览，纵向滚轮继续滚动页面。
- 节点按阶段配色，“遇到再学”节点以虚线边框区分。点击浮窗查看知识范围、理解要点、关联基础与可选混练建议。
- 递归/分治、初识贪心/贪心分类、基础数据结构上下与进阶、基础图论到进阶图论、基础数学到计算几何等关系按已确认框架组织。
- 知识树与路线可相互定位，路线资料可打开原有笔记阅读器。路线公共资料仅展示公共笔记；个人笔记继续在知识树个人范围查看。

## 资料和个人记录

- 路线节点通过稳定内容标识关联原课程资料、知识点及题单。管理员继续使用既有权限和SHA冲突校验维护介绍、目标和官方精选题单。
- 个人题单保存在账号及资料来源隔离的个人记录中；保存失败保留输入并可重试。
- 原完成状态、任务、题单和未知元数据保留；新的当前关注字段不覆盖旧记录。首次读取GitHub旧记录时保留原键，自定义服务不接管来源不明的旧记录。
- 新路线不显示旧关卡打卡、完成率与任务卡；旧公共课程数据及接口保留兼容，旧课程编排入口不作为图形路线编辑器。

## 发布前验证

- 严格TypeScript、生成产物一致性、语法及课程数据检查通过。
- 20组界面回归通过，含路线几何、缩放、主题、390px布局、鼠标滚轮、笔记阅读、管理员与个人题单保存失败重试、资料隐私、来源和账号隔离。
- 真实Electron验证隔离preload、本地IPC、当前关注磁盘保存与重启恢复，以及旧完成/任务/题单/未知元数据保留。
