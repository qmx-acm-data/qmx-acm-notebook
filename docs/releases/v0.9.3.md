# 拾题 v0.9.3 · 主页比赛提醒

- 主页顶部新增统一的比赛提醒框，汇总洛谷、Codeforces、AtCoder、牛客官方近期赛程。比赛以紧凑横条展示，进行中的比赛优先，其余按开赛时间排序，每个平台最多显示最近三场未结束比赛。
- 显示北京时间开赛时间、官方赛时与每秒更新的倒计时。开赛后切换为距结束时间，结束后移除；比赛名称和平台入口可打开官方页面。
- 四个平台分别缓存在本机，启动先显示缓存，再后台刷新。支持手动刷新和十分钟自动刷新；单个平台获取失败保留已有赛程，遵守请求间隔及平台限流提示。
- 每场比赛提供“不参加”按钮，点击后立即隐藏，刷新与重启后仍保留。点击“已隐藏 N 场 · 恢复”打开选择框，可勾选指定比赛恢复，支持全选、全不选和取消；保存失败保留选择并回滚。
- AtCoder 比赛名称旁新增 ABC、ARC、AGC、AHC 类型标签，恢复选择框中也显示对应标签。
- 修复窄窗口下开赛时间与赛时重叠，以及隐藏比赛较多时恢复窗口底部操作可能被裁切的问题。

用户已完成本地桌面客户端交互验收并明确授权发布 0.9.3。验证包含 184 项 Node 测试、比赛提醒与导航界面回归，以及实际打包客户端的四平台赛程、倒计时、缓存、选择恢复持久化与类型标签检查。洛谷及牛客展示官方列表提供的近期比赛，不包含全部历史或私有比赛；实际赛程以官方安排为准。GitHub OAuth 在线投稿仍未完成独立验收。

Electron runtime 保持 40.10.6。Windows 安装程序未进行 Authenticode 签名，macOS 包未签名公证。正式 Release 发布后合并更新通道 PR，现有客户端才会收到应用内更新。
