# 拾题 v1.1.0 · 差分下载与便携更新修复

## 差分下载

更新仍使用固定公钥的 Ed25519 签名、固定源码提交和 SHA-256 校验。新增独立签名差分清单：本机旧应用包的版本、大小和哈希匹配时，优先下载补丁，复用已有应用字节重建新版；完整新版校验通过后，沿用原位置替换和失败恢复流程。

- 使用内容分块匹配与 Brotli 压缩，仅传输复制指令和新增内容。
- 仅提供比完整应用包小至少 10% 的补丁；界面显示补丁下载量和完整包大小。
- 缺少适用补丁、旧包被修改、补丁下载或重建失败时，自动回退完整应用包。
- 原有完整包清单保持兼容，旧客户端仍可检查更新。
- Electron 运行时版本不匹配时，仍需完整安装程序。

**首次迁移：1.0.0 及更早客户端不具备补丁重建能力，升级到 1.1.0 这一次仍需完整应用包；安装本版后，后续兼容更新才会优先使用差分。便携旧版还保留了拒绝文件升级的检查，需退出客户端后用本版完整便携目录覆盖一次，保留个人数据，不必先安装安装版。**

差分大小取决于实际变更，不承诺每次均小于上一次；目标是对同一个目标版本减少相对于完整包的实际下载量。

## 界面与可靠性

- 移除“我的题解”“学习统计”“讨论交流”入口和独立页面，保留已有记录、草稿、收藏及任务数据。本地保存后直接进入详情，可编辑和收藏，收藏后从个人收藏访问。
- 修复便携升级错误要求卸载程序的问题。
- 更新助手启动失败后取消未执行事务，允许在同一客户端中重新尝试。
- 清理失败下载和已结束事务中的应用副本；完整且验证通过的用户数据备份保留最近两份，小型事务回执保留最近三份。活动事务和未知文件保留。

## 验证

差分验证覆盖真实应用包生成与精确重建、仅下载补丁的流量计数、旧文件变化、签名或补丁损坏、重建结果不符、完整包回退及链接路径保护。重复升级、失败回滚、重启恢复和本地记录持久化保留回归。正式构建与各平台成品验收结果以发布 Actions 为准。
