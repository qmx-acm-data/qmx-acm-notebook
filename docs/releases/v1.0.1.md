# 拾题 v1.0.1 · 入口精简与更新存储修复

## 界面

移除“我的题解”“学习统计”“讨论交流”的侧边栏入口和独立页面。已有本地记录、草稿、收藏与复习数据保留。本地保存后直接打开题解详情，可编辑或收藏；收藏后从个人收藏访问。公共题库仍只展示已上传的正式题解。

## 更新修复

- Windows / Linux 文件更新不再要求 Windows 卸载程序，便携目录可直接进行签名文件替换。
- 重新检查更新时移除本进程之前下载的旧应用包；失败下载清理部分文件和空暂存目录。
- 更新助手未成功启动时，取消未执行的事务并保留验证后的下载，同一客户端进程中可重新尝试，不再被旧事务卡住。
- 启动恢复完成后清理已结束事务的暂存应用、旧应用备份和安装目录交换副本；历史副本也会按相同验证规则回收。
- 完整且哈希验证通过的个人数据备份保留最近两份，小型事务回执保留最近三份。未完成事务、未知文件、链接目标和损坏备份保留。
- 新下载目录记录进程所有者，运行中的下载不清理；旧版无标记下载至少保留 24 小时，避免误删另一个进程正在下载的文件。

更新下载仍为完整 app.asar，不是差分补丁。这次修复针对磁盘副本累积及便携版被拒绝，不保证单次下载体积随改动大小变化，也不保证进程运行内存下降。

## 旧版迁移

旧版在运行新代码之前就会拒绝便携升级，因此仅反复点击检查更新无法修复旧客户端自身。退出旧客户端，将完整新版便携包解压并覆盖原程序目录一次，保留系统用户数据目录；不要只替换 EXE。安装版可通过完整安装程序覆盖原位置。

## 验证

- 连续六轮同体积便携升级，事务应用副本全部清理，用户数据占用在保留上限后稳定。
- 签名、篡改、替换失败回滚、中断恢复、活动进程与链接路径保护均通过回归。
- 导航和本地题解保存、编辑、收藏、刷新恢复检查通过。
