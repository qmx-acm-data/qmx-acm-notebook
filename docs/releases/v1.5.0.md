# 拾题 v1.5.0 · 叶子笔记阅读与 Markdown 简介

本版精简算法树与学习路线的阅读结构，明确目录和知识叶子的身份，让读者更容易找到需要学习的笔记。

## 目录与叶子

- 只有真实算法或知识叶子保存笔记；目录只组织子节点，不提供目录笔记列表或上传入口。算法扩展为目录后，原笔记继续对应其内容叶子，不移动已有文件。
- 修正实际内容端点被误标目录的情况；上传选择器和后端保存校验都限制真实叶子，目录简介不获得笔记权限。
- 学习路线范围节点只展示一个 Markdown 简介与具体叶子入口，进入叶子再阅读笔记。原有目标、注意、混练、关系和题单说明合并进简介，不再堆叠单独模块。

## 统一阅读与管理员维护

- 算法树、学习路线和公共／个人范围统一为“简介 → 精选笔记 → 全部笔记”；全部笔记排除已精选内容。
- 简介采用安全渲染的 Markdown，管理员可编辑并预览；精选可多篇选择和取消，不再清除其他笔记的精选标记。
- 节点内容保存到独立公共文件，带 fresh admin、笔记归属、来源和 SHA 校验。旧算法拆分后的简介保留原文件身份；路线目录简介按独立节点标识保存，避免共享旧课程条目造成互相覆盖。
- 保存失败保留草稿，切换知识点后保持最新简介与 SHA；不可用的旧精选引用可以显式移除，其他范围引用不静默删除。异步保存不会覆盖后来打开的目录。

## 搜索与展开

- 新增“仅看已有笔记”，按当前公开／个人范围过滤并保留必要祖先。
- 无条件重新进入、刷新或清除筛选恢复嵌套收起；有搜索、难度、属性或已有笔记条件时，继续展开命中路径。
- 移除条件筛选时右侧额外的全局结果、匹配知识节点和匹配笔记模块；右侧继续显示当前目录或叶子的正常阅读内容。
