# 拾题 v1.2.6 · TypeScript 模块化与维护基础

本版以保持 v1.2.5 的界面、操作流程和数据兼容为目标，完成内部模块化与 TypeScript 重构。无需迁移个人题解、收藏、计划、设置或学习进度。

- 主进程、服务、更新/恢复、发布与数据工具、浏览器预览服务器及界面业务改为 TypeScript 源码；全部 34 项 IPC 方法与订阅定义明确契约。
- 拆分筛选、编辑、阅读、账户、算法工作区及主进程会话/IPC 等职责，界面通过显式导入连接，构建为统一应用包，避免重复模块状态。
- 开发、测试与未签名打包使用同一构建布局；类型和生成漂移检查帮助发现遗漏。开发源码映射仅进入本地构建副本，发行包不包含应用源码、编译器或 map。
- 增加仓库 `AGENTS.md`，明确后续 AI 修改 TS 源码、通过命令生成运行文件、保留数据与权限边界，并按影响执行验证。
- 扩大发布前可信输入比较，涵盖源码、生成器、依赖、配置与被测试执行的工作流，确保进入签名流程的应用来自已审核输入。

保留多仓库隔离、公开题库同步、匿名 Gitea 预览、Markdown/公式与离线代码格式化、原生计划和连续差分更新。Electron runtime 保持 40.10.6，签名公钥和更新协议保持兼容；macOS 继续使用完整安装包手动更新。

发布前本地已完成严格类型、生成漂移、语法和数据检查，509 项单元测试中 508 项通过、1 项因本机符号链接权限跳过；13 组界面回归、真实 Electron 及未签名 Windows 成品的格式化和保存/重启检查通过。五平台最终构建与签名产物以本版本发布流水线及验收记录为准。真实账号 OAuth、组织权限和远端写入仍需按实际账号验收，模拟测试不代替该流程。
