# 拾题 v1.2.6 · TypeScript 模块化与维护基础

本版保持 v1.2.5 的界面、操作流程和数据兼容，完成内部模块化与 TypeScript 重构。无需迁移个人题解、收藏、计划、设置或学习进度。

- 主进程、服务、更新/恢复、发布与数据工具、浏览器预览服务器及界面业务改为 TypeScript 源码；全部 34 项 IPC 方法与订阅定义明确契约。
- 拆分筛选、编辑、阅读、账户、算法工作区及主进程会话/IPC 等职责，界面通过显式导入连接，构建为统一应用包，避免重复模块状态。
- 开发、测试与未签名打包使用同一构建布局；类型与生成漂移检查帮助发现遗漏。开发源码映射仅进入本地构建副本，发行包不含应用 TS 源码、编译器或 map。
- 新增 AGENTS.md，要求 AI 修改 TS 源码、通过命令生成运行产物，并保留数据、权限和更新边界。
- 扩大发布可信输入比较，涵盖源码、生成器、依赖、配置与测试中执行的工作流。

保留多仓库隔离、公开题库同步、匿名 Gitea 预览、Markdown/公式、离线代码格式化、原生计划和连续差分更新。Electron runtime 保持 40.10.6，签名公钥及更新协议兼容；macOS 继续使用完整安装包手动更新。
