# 拾题 v1.6.2 · 算法目录管理与 Markdown 阅读

- 仓库管理员可以编辑内置算法叶子和仓库自建节点，修改名称、难度与学习范围。删除前会确认；仍有子节点、算法笔记、已保存的简介、公共课程或 Trick 前置引用时，客户端会提示原因。内置叶子的修改保存在当前资料库，旧客户端仍按内置算法表显示。
- 有仓库写入权限的作者可以编辑和删除自己的个人算法笔记。管理员可以管理公共笔记。编辑时可以重新选择算法叶子，保留原作者和文件路径。
- 行内公式支持美元符号内侧空格，例如 `$ [1,n] $`。题解、算法笔记和 Trick 阅读页根据正文标题生成可折叠目录，点击即可跳转。

更多操作见 [使用指南](../USAGE.md) 和 [算法笔记](../ALGORITHM_NOTES.md)。
