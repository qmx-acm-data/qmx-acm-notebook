# 拾题 v1.6.1 · Trick 等级排行与洛谷难度修复

## 主要变化

- Trick 新增等级排行：S（优先掌握）、A（推荐掌握）、B（按需查阅）、C（专题补充）、D（少见场景）、E（备查参考），以及独立的「未评级」。等级表示满足前置后的学习优先级，不等同于算法难度。
- 「最近更新」与「等级排行」都保留紧凑列表，标题右侧新增「前置算法」列，标签可搜索。详情把已录入的前置画为依赖图；可勾选「已学」并查看完成进度，排行可以仅显示满足全部前置的 Trick。
- 维护者可编辑等级、前置算法和推荐理由。建议编辑带评级的 Trick 前先升级到 v1.6.1：旧客户端保存文档时可能移除它不识别的评级字段。
- 洛谷原生难度按官方 0～8 编号解析，纠正 5～7 档错位并恢复编号 8。旧索引可使用随包提供的官方快照恢复难度；同题的空难度记录不再遮住已缓存的原生等级。此修复不依赖 CLIST。
