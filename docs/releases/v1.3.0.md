# 拾题 v1.3.0 · 六套配色与新版闯关学习

本版新增独立于明暗模式的六套配色，统一卡片布局，并包含新版学习路线、个人学习任务与管理员公共关卡编辑。

## 外观与阅读体验

- 提供瓷白、晴空蓝、雾紫、樱粉、暖杏、海盐青六套配色，每套均支持浅色和深色；切换配色保留当前明暗模式，切换明暗模式保留当前配色。
- 公共题库、本地题解与个人收藏采用大小适中的卡片，保留清晰边界、间距和阅读区；浅色与深色共用布局。
- 顶栏可直接切换明暗与配色。设置窗口支持即时预览，取消或关闭恢复打开前的外观，保存后保留选择并在重启后恢复。旧版卡片主题自动迁移为浅色＋暖杏，无需手工重设。
- 按钮、导航、筛选和选中态使用统一的配色；平台标识、原生难度、复习状态等语义颜色及代码高亮、作者指定正文颜色继续保留，避免配色改变已有含义。
- 侧边导航的选中条与展开、固定状态衔接更稳定。算法目录的名称与难度提示悬停即显示，支持嵌套文字、图标、键盘焦点与视口边缘；修复滚动后的提示残留，以及选择知识点时重建目录 DOM 导致的滚动、焦点和选中状态问题。窄屏内层面板滚动到底或顶后，可继续滚动外层页面。

## 新版闯关学习

本版包含新合并的[学习路线与公共关卡改进（PR #48）](https://github.com/qmx-acm-data/qmx-acm-notebook/pull/48)，这些功能尚未包含在 v1.2.6 中。

- 课程按知识与实际成果重构为 14 个教学章节，另含第 0 章竞赛导览，共 15 章、58 个非导览学习段或独立路线、201 关，关联 188 个真实知识树节点。每段按内容自然拆关，区分核心、推荐进阶、选修与路线基础；高级方向分别计算完成度。
- 开始学习后，学习关提供笔记学习与题单练习两项任务，混练与验收关提供练习任务。个人题单通过浮窗添加，任务勾选、个人题单和学习状态保存在原账号与资料库对应的学习记录中；自行记录完成不代表自动评测通过。
- 官方精选题单直接显示在关卡详情，尚未配置时明确提示未发布。管理员可在标题旁添加或编辑一个官方题单，并编辑公共介绍与核心目标，发布前可预览公共版。
- 公共关卡保存在当前资料库，按资料来源同步和离线缓存；服务端校验管理员权限及版本 SHA，冲突需重新同步。其他成员可查看公共内容，个人题单与学习状态不会写入公共关卡文件。
- 旧路线第 1–14 章的 168 个关卡记录保留为历史，新关卡使用独立身份，旧完成记录不会被误算为新课程进度；第 0 章关卡身份与原账号、资料库进度命名空间继续保留。

课程范围、数据来源与历史进度规则见[学习路径设计说明](../algorithm-research/learning-path-design.md)。

## 下载与升级

发布后可从 [v1.3.0 Release](https://github.com/qmx-acm-data/qmx-acm-notebook/releases/tag/v1.3.0) 下载：

- Windows x64：`QMX-Notebook-Setup-1.3.0.exe` 或便携 ZIP。
- Linux x64/ARM64：对应 tar.gz。
- macOS Intel/Apple Silicon：对应 DMG 或 ZIP，继续通过完整安装包手动更新。

升级前建议备份个人数据，安装与备份步骤见[使用指南](../USAGE.md)。正式 Release 开放下载后，仍需验收并合并更新通道 PR，现有客户端才会收到应用内更新。
